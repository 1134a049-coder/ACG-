🎓 Python 核心考點大白話隨身讀 (點選各主題展開)

這裡幫大家整理了考題中反覆出現的 Python 技術考點，並全部換成「人話」搭配生活譬喻解釋。點選下方各個主題分類，就能一次性閱讀與快速複習喔！

📦 1. 基礎語法與變數命名 (縮排、命名、註解與輸入) ▼

🧬 Python 縮排 (Indentation)：俄羅斯套娃的排隊線

比喻：就像俄羅斯套娃，外層的套娃裝著內層的套娃。Python 用「空格縮排」來表達這段程式「屬於誰」。如果沒對齊，直譯器就會像看到排隊隊伍亂掉一樣生氣罷工，拋出 IndentationError！

🏷️ 變數命名規則 (Naming Rules)：新寵物的身份登記

比喻：幫變數取名字就像給寵物登記名字。不能用數字開頭（不然系統會分不清是名字還是數字），不能有空格或怪符號，更不能用 Python 本身已經註冊好的「關鍵字」例如 if、def、for（就像你不能幫寵物取名叫「總統」或「身份證」一樣，會引起系統混亂）。

✍️ # 註解 (Comments)：悄悄話便條紙

比喻：就像你在課本旁邊用鉛筆寫的「悄悄話小筆記」。老師（直譯器）在改考卷時會自動忽視這些小筆記，只看你寫的正式答案，因此 # 後面的內容完全不影響程式的運行。

📥 input() 輸入與類型轉換 (Type Casting)：海關安檢與外幣兌換

比喻：input() 就像是一個海關安檢口，所有通過的人都會被套上統一的「文字標籤（字串）」。就算你輸入了數字「100」，在 Python 眼裡也是文字的 "100"（就像拿到外國遊戲代幣一樣，不能直接在本地買便當）。如果想要算術，必須用 int("100") 換成整數（台幣）或用 float("100.5") 換成小數，否則會報錯！

🔢 2. 算術運算與邏輯運算 (除法、整除、餘數、邏輯與優先權) ▼

🥢 / (真除法) vs // (整除) vs % (取餘數)：平分披薩、超市買餅乾與發撲克牌

比喻：

  • 單斜線 `/` 就像是「切披薩」，5 個人分 2 個披薩，每人分到 2.5 片。即使剛好整除（如 4 / 2），結果也會是 2.0（帶有小數的浮點數）。
  • 雙斜線 `//` 則是去超市「買整包餅乾」。一包 2 元，你口袋有 5 元，你最多只能買 2 包完整的餅乾，收銀員不會拆開賣你半包。所以 5 // 2 = 2。如果金額帶小數（5.0 // 2），就像是用電子錢包嗶，扣款顯示有小數點（2.0），但買到的數量依然是整數的包數。
  • 百分號 `%` 則是「發撲克牌剩下的餘牌」。有 7 張撲克牌，平分給 3 個人，每人分到 2 張，最後桌上還剩下 1 張沒辦法平分的「餘牌」。所以 7 % 3 的結果就是 1（餘數）。

⚡ ** (次方 / 開根號)：細胞分裂與面積求邊長

比喻：

  • 次方的 `x ** 2` 就像是細胞分裂。`5 ** 2` 代表 5 個細胞各自再分裂成 5 個，最後得到 25 個。
  • 開根號的 `x ** 0.5` 則是「還原面積求正方形邊長」。比如一個面積為 9 的正方形，它的邊長就是 3.0。所以 9 ** 0.5 = 3.0。

🚦 and, or, not (邏輯運算子)：出門許可證

比喻：

  • and (而且)：就像是「爸爸和媽媽都答應，才能出門」。只要其中一個說 No（False），你就不能去（False）。
  • or (或者)：就像是「爸爸或媽媽有一個人答應，就能出門」。只要有一個人說 Yes（True），你就能去（True）。
  • not (相反)：就像是叛逆期的唱反調。把 Yes 變成 No，把 No 變成 Yes。例如 `not True` 會變成 `False`。

👑 運算子優先順序 (Operator Precedence)：排隊買票的 VIP 通道

比喻：就像數學的「先乘除後加減」。Python 算術也有嚴格的排隊規矩：最優先的是括號 ()，再來是次方 **，接著是乘除與取餘數 * / // %，最後才是加減 + -。

🎫 3. 字串操作與格式化 (字串切片、連續重複、拆裝綵帶與跳脫) ▼

🎫 字串切片 slice [start:stop:step]：小火車切票與間隔站

比喻：就像小火車切段。`start` 是起點站，`stop` 是終點的前一站（不包含終點站本身），`step` 是每次跳幾站。例如 `"012345"[1:5]` 是指從第 1 站開始上車，到第 4 站就下車，第 5 站是禁區不能坐！

🖨️ 字串重複相乘 ("abc" * 3)：連續蓋印章

比喻：你手上有一個刻著 `"abc"` 的印章，你連續在紙上蓋 3 次，紙上就會出現一長串連在一起的 `"abcabcabc"`。

✂️ split() vs strip() vs join()：剪綵帶、洗水果與穿糖葫蘆

比喻：

  • split() (剪刀剪綵帶)：如果有一條用逗號隔開的綵帶 "A,B,C"，你在逗號的位置拿剪刀剪下去，就會得到三段獨立綵帶的列表：`["A", "B", "C"]`。
  • strip() (清洗水果)：洗水果時，你只會洗乾淨水果「頭尾」的泥土（空白或換行符號），而水果「中間」的果肉保持原樣不受波及。
  • join() (穿糖葫蘆)：用竹籤（例如逗號 `","`）把蘋果、香蕉、草莓（列表 `["apple", "banana", "strawberry"]`）串起來，變成 `"apple,banana,strawberry"`。

🖨️ upper() / lower() vs len()：大/小寫鍵與排隊人數點名

比喻：

  • upper() / lower() 就像影印機的「全大寫/全小寫」複印鍵。不論你丟入什麼原稿，它都會把英文通通轉換，但標點符號、空格或數字就像印表機印不出顏色的地方一樣，保持原樣不受影響。
  • len() 就是拿計數器點一下排隊隊伍，告訴你總共有多少個人（字元數或元素數）。

🧙 跳脫字元 (Escape Characters) \n, \t：排版魔法按鍵

比喻：在代碼中，`\n` 就像是鍵盤上的 **Enter 換行鍵**，`\t` 則像是 **Tab 縮排鍵**。它們雖然在代碼裡看起來是兩個字元，但在螢幕上會施展魔法變成不可見的排版動作！

🗄️ 4. 容器型別與成員檢查 (列表、元組、字典、成員運算與操作) ▼

🗄️ list (列表) vs tuple (元組) vs dict (字典)：多層抽屜櫃、水泥保險箱與掛牌櫃

比喻：

  • list (列表 `[]`)：抽屜從上到下編號 0, 1, 2...，你可以隨時拉開抽屜修改內容、塞新抽屜、或丟掉舊東西。
  • tuple (元組 `()`)：一旦把東西放進去並水泥封死，就再也不能修改或新增內容。安全性極高，常用在不可改變的設定資料。
  • dict (字典 `{}`)：你要拿櫃子裡的玩具不用知道它是第幾個櫃子，只要認明掛牌上的名字（Key），比如「小明的櫃子」，就能精準拿到對應物品（Value）。

🔍 in & not in (成員運算子)：檢查口袋有沒有糖果

比喻：`in` 就像問：「我的口袋裡有沒有糖果？」，有的話回答 True，沒有就回答 False；`not in` 則是反過來，問：「我的口袋是不是沒有糖果？」。常用於檢查某個鍵值是否存在於字典或某元素在列表內。

🏃 append() vs insert() vs pop()：排隊尾、插隊與叫最後一個人滾蛋

比喻：

  • append()：就像是排隊時乖乖排到隊伍的最尾端。
  • insert(i, x)：則是霸道地插隊到第 `i` 個人的位置，讓原本排在後面的人通通往後退一步。
  • pop()：像是主管喊話：「排在最後面的那個人可以下班了！」，直接把隊伍最後一個元素拿出來並丟掉。

🔄 5. 流程控制與迴圈操作 (if-else、for/while 迴圈、控制語句) ▼

🚥 if - elif - else 條件分支：遊樂園的分流入口

比喻：就像遊樂園的驗票口。如果身高超過 140 走 `if` 通道；介於 110 到 140 走 `elif` 通道；其餘的人（低於 110）一律走 `else` 通道。程式只會挑一條符合的通道走，走完就離開，不會重複走！

🔁 for 迴圈與 range()：點名小老師與爬樓梯禁區

比喻：

  • for 迴圈：就像是「點名小老師」拿著一份名單，把名單上的每個人（元素）依序叫出來做一遍同樣的事。
  • range(start, stop, step)：就像爬樓梯。`range(1, 5)` 代表從第 1 階起步，一次爬 1 階，爬到第 4 階就必須停下來，因為第 5 階（stop）是禁區不可觸碰。所以它只包含 `1, 2, 3, 4`！

🔄 while 迴圈：無盡的跑步機

比喻：`while` 就像是家裡的跑步機，只要「電源開關是開的 (True)」，它就會一直轉（重複執行程式碼），直到你把開關關掉 (False) 或拔掉插頭才會停下來。

🛑 break vs continue vs pass：下課鈴、跳過難題與佔位隱形人

比喻：

  • break：就像是下課鈴聲響起。你一聽到，立刻停下手邊的所有工作，衝出教室（直接中斷並逃離整個迴圈）。
  • continue：就像是寫考卷時遇到不會寫的難題。你決定「這題先空著，直接寫下一題」（跳過本次迴圈後半段的指令，直接進入下一次迴圈）。
  • pass：就像是佔位子用的隱形人。Python 語法規定某個地方一定要有縮排代碼（例如 if 條件下面），但你現在還沒想好要寫什麼，就放一個 `pass` 告訴系統「這裡先空著，我只是路過，不要報錯」。

🛠️ 6. 函式定義與作用域 (def 函式、全域與區域、math 數學模組) ▼

🔌 def 函式定義與參數：廚房果汁機

比喻：定義函式就像是「買一台果汁機並貼上說明書」。參數是放進去的「水果」，函式內容是「攪拌過程」，而 `return` 就是最後倒出來的「果汁」。定義好之後，必須按下開關（呼叫它）它才會開始運作。

🌍 global (全域) vs local (區域) 變數：公共電話與私人手機

比喻：

  • global (全域變數)：like 公園的公共電話，任何人（每個函式）都可以走過去使用或修改它。
  • local (區域變數)：則像你的私人手機，只有在你的房間裡（特定的函式內部）才能用，外面的路人根本碰不到。

📐 math 常用函式 (floor, ceil, sqrt)：地心引力、天花板與求邊長

比喻：

  • math.floor(x) (地板)：就像重力把人拉向地面，無論小數點後是多少（如 3.9），通通無條件捨去成整數 3。
  • math.ceil(x) (天花板)：就像熱氣球升向天花板，只要有小數點（如 3.1），通通無條件進位成整數 4。
  • math.sqrt(x) (平方根)：就是「求正方形面積的邊長」。比如面積為 16 的正方形，邊長就是 4.0。

💾 7. 檔案讀寫與例外處理 (檔案模式、讀寫方法、try-except、常見錯誤) ▼

📁 open() 的讀寫模式 r/w/a/b：圖書室看書、重新粉刷與接龍

比喻：

  • 'r' (唯讀)：就像在圖書室看書，只能看不能修改。檔案如果不存在會拋出 `FileNotFoundError`。
  • 'w' (覆寫)：就像重新粉刷牆壁。一打開檔案會把舊內容全部抹除乾淨，寫入全新的內容。如果檔案不存在會幫你自動建立一個。
  • 'a' (追加)：就像寫接龍故事，新內容只會黏在原本檔案的最尾端，絕不破壞原本的資料。
  • 'b' (二進位)：就像解讀加密電報本，處理圖片、音樂、PDF 等非純文字的檔案時，要加 'b' (如 'rb', 'wb')。

📄 read() vs readline() vs readlines()：鯨吞、蠶食與整理成冊

比喻：

  • read()：就像一口氣把整本書吃下去，把整份檔案包裝成單一個超長字串。
  • readline()：就像是一行行慢慢看，每次呼叫只讀取檔案裡的一行。
  • readlines()：就像把書拆成一頁頁並裝訂成講義，把檔案裡的每一行切開，收集成一個字串列表。

🛡️ try - except - finally：防摔護具與必定執行的收尾

比喻：

  • try：就像你在嘗試走一條可能有香蕉皮滑倒的路。
  • except：就像是準備防摔護具，一旦滑倒（程式出錯）就立刻保護你，不讓程式崩潰。
  • finally：就像是「不管你有沒有滑倒，最後都要回家洗手」，是用來做最後必定執行的收尾動作（例如關閉已打開的檔案資源）。

🚨 考題常見的錯誤類型 (Exceptions)

比喻：

  • IndexError (找錯座位)：一排只有 3 個座位 (0, 1, 2)，你卻硬要第 4 個人 (3) 坐下，因為找不到座位而引發錯誤。
  • TypeError (果汁機放鐵釘)：試圖把「文字 (蘋果)」和「數字 5 (鐵釘)」相加。型態不同無法融合，機器報警罷工。
  • FileNotFoundError (圖書館借無書)：去圖書館借一本根本沒上架的書，直譯器回報「找不到檔案」。
